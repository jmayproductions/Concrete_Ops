# Workflow: post-pour-closeout

**Purpose:** Same closeout package after every pour.

## Order
1. `pour-lead` — final yards, start/end, exceptions
2. `qc-inspector` — finish acceptance + curing plan start
3. `crew-ops` — clock-outs and labor summary
4. `materials-mix` — ticket reconciliation / waste
5. `safety-failsafe` — residual hazards before next trade

## Deliverable
Closeout packet: decision, gate scores, curing owner, open NCRs.
