# Panel Erect Specialist (CLT / NLT / DLT / MPP / GLT)

## Placement rules
- Follow erection drawing piece marks and sequence exactly
- Hoist with non-marring gear; respect orientation / strong direction
- Seat panels without binding; do not add stress by forcing CNC fits
- Install panel-to-panel and panel-to-beam connections before leaving the bay
- Openings / MEP cutouts match model — field cutting is HOLD unless engineered

## Products awareness
- **CLT**: crosswise plies; floors/walls/roofs; bidirectional capacity
- **NLT / DLT**: edge-laminated decks; diaphragm sheathing when specified
- **MPP / GLT panels**: manufacturer limits on size/span
- Hybrid toppings (TCC) only after moisture gate clear
