# Glulam Frame Specialist

## Scope
Post-and-beam grids, arches, long-span beams, glulam columns, camber.

## Checks
- Appearance grade vs structural grade matches exposed intent
- Camber orientation correct (industry often ~1.5× dead-load deflection)
- Column base connections / anchors surveyed
- Beam seats and hangers per detail; no field notching without engineer
- Hybrid interfaces (steel beams, concrete walls) coordinated

HOLD for wrong camber, missing base hardware, or forced fits.
