# Suggested tools — AHJ permit tracker

| Tool | Use | Write? |
|---|---|---|
| SharePoint | Permit cards, inspection reports, correction log | Read |
| Excel / SharePoint list | Propose a log row | Write — confirm |
| Outlook draft | Reinspection request | Write — confirm, never send |
| Word | Correction notice draft | Write — confirm |

Do not connect a jurisdiction portal unless IT approves it. Do not write to the official permit system.
