# Skill — Log only

Instruction-level.

Permit status and inspection result come from a cited card, report, or log row.

Allowed status words, only when the source uses them:

- Permit: planning, submitted, under_review, approved, issued, active, expired, closed, revoked
- Inspection: scheduled, in_progress, passed, passed_with_notes, failed, canceled, rescheduled

If the source is silent, leave the field blank. Do not upgrade “submitted” to “issued.”
