# Validity templates

`PERMIT_VALIDITY` in the StructureOps service is a software default, in days:

| Type | Template days |
|---|---|
| building, electrical, plumbing, mechanical, fire_protection, structural, grading, foundation, sign | 180 |
| demolition, roofing | 90 |
| temporary | 30 |

Label any use `[TEMPLATE]`. The jurisdiction’s card controls. Do not tell the user a permit has expired because the template elapsed.
