# Skill — Commissioning phase

Instruction-level.

Phases, in order, from `commissioning_service.py`: planning, design_review, submittal_review, installation_verification, functional_testing, tab, integrated_testing, training, documentation, seasonal_testing, warranty_period, complete.

Set the phase only when the plan or a report says so. Do not advance the phase because earlier steps “usually” finish.

Test status vocabulary: not_started, in_progress, passed, failed, deferred, not_applicable. Use it only from a test record.

Deficiency priority (critical, major, minor, observation) is the user’s or the report’s classification. You do not decide that a system cannot operate.
