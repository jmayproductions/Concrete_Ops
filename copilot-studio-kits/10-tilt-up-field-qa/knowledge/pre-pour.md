# Checklist — Pre-pour (casting bed)

| Id | Item | Requirement in the engine |
|---|---|---|
| PP01 | Casting bed clean and level | No debris, proper grade |
| PP02 | Bond breaker applied | Complete coverage, no gaps |
| PP03 | Rebar placement verified | Spacing, cover, ties per drawings |
| PP04 | Lift inserts positioned | Location per shop drawings, capacity verified |
| PP05 | Embedded plates/anchors set | Elevation, alignment, bracing secure |
| PP06 | Openings formed | Dimensions, location, bracing adequate |

PP03 and PP04 need the drawings or shop drawings. Without them, Unknown.
