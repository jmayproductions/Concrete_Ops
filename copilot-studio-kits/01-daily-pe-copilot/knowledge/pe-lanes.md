# PE workflow lanes

Use this to classify the request and to recommend a work product.

| Lane | Typical inputs | Typical output |
|---|---|---|
| RFI | Drawings, specs, field note | RFI draft |
| Submittal | Spec section, product data | Completeness / coordination note (not an approval) |
| Takeoff | Drawings, schedules | Structured quantity list with assumptions — no invented prices |
| QA/QC | Spec, ITP, approved submittal | Checklist draft, hold points from sources only |
| Daily report | Field notes, photos, weather | Daily report note |
| Meeting minutes | Agenda, last minutes, open items | Action-item list |
| Change event | Bulletin, ASI, field extra | Change summary, impacts UNKNOWN unless sourced |
| Procurement | Submittal log, lead times | Long-lead / release reminder |
| Drawing/spec review | Revision set | What changed, superseded flags |
| Punch | Walk notes, photos | Punch item draft |
| Closeout | Spec closeout section, log | Missing-items checklist |
| Interview/training | No project file required | Process teaching, labeled as general |
