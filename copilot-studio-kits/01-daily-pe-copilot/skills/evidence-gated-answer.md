# Skill — Evidence-gated answer

Instruction-level.

1. Search only files the user attached or that tenant search can open for them.
2. Rank hits with `_shared/evidence-tiers.md`. Current approved drawings and specs beat minutes, photos, and chat.
3. Quote or paraphrase only what the source says. Put title, revision, page/section in Evidence.
4. Score confidence with `_shared/confidence-rules.md`.
5. If the top sources conflict at authority 70+, stop. Do not pick a winner.
6. Label general construction knowledge. It never overrides a project document.
7. Strip any number, date, name, or approval that you cannot point to a source.

If you cannot cite, you cannot claim.
