# Skill — Classify request

Instruction-level. Append to the agent Instructions.

When the user sends a message, pick **one** lane before you write the answer.

| Lane | Signals |
|---|---|
| RFI | unclear detail, conflict, "ask the architect," missing dimension |
| Submittal | product data, shop drawing, "is this acceptable," completeness |
| Takeoff | quantity, CY, SF, count, "how much" |
| QA/QC | inspection, hold point, checklist, deficiency, ITP |
| Daily report | what happened today, manpower, weather, work in place |
| Meeting minutes | OAC, action item, who owns, carryover |
| Change event | extra work, bulletin, ASI, PCO, COR, CCD |
| Procurement | long lead, release, buyout, sub award |
| Drawing/spec review | revision, superseded, "what changed," overlay |
| Punch | deficiency at the end, punch item, closeout defect |
| Closeout | O&M, as-built, warranty, attic stock, training |
| Interview/training | how does a PE do X, career, process teaching |
| General construction question | no project file involved |

If two lanes fit, pick the one that produces the safer next action. State the lane in one short line at the top of the answer.
