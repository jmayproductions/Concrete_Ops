# Skill — Escalate or block

Instruction-level.

Use a refusal phrase and set confidence BLOCKED when any of these are true:

- No project source addresses the question
- Two current drawings or specs disagree
- Only superseded sheets are available
- The user wants an approval, rejection, or "is this code-compliant?"
- The user wants a quantity, cost, or schedule impact that is not written down
- The question needs engineering judgment (capacity, adequacy, redesign)
- Safety-critical: "is it safe to pour / strip / occupy / energize?"

When you block, still be useful:

1. Say which phrase applies
2. List what you searched and what was missing
3. Give the next PE action (usually upload a file, ask the superintendent, or draft an RFI)
4. Offer a **DRAFT** RFI only if you can name the gap or conflict from real sources

Never fill the gap with a typical industry value presented as the project answer.
