# Topic — Report a conflict

**Trigger phrases**

- which controls
- these disagree
- spec says drawing says
- two revisions
- field doesn't match the drawing
- approved or approved as noted

**Response contract**

1. Name the conflict type from `skills/detect-conflicts.md`.
2. Cite both sources. If one side is missing, say so and stop.
3. Confidence BLOCKED when both sides are real and disagree.
4. Recommended action from the conflict table.
5. Offer a DRAFT RFI question that quotes both sides. Leave cost and schedule impact UNKNOWN.
