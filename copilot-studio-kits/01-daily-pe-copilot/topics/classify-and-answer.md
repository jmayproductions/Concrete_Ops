# Topic — Classify and answer

**Trigger phrases**

- what does the spec say
- draft an RFI
- review this submittal
- what's blocking
- what changed
- is this acceptable
- what should I take to OAC
- check the drawing
- closeout items
- punch this

**When to use**

Default topic for any PE question that has, or should have, project documents.

**Response contract**

1. State the lane in one line.
2. Answer with the Required Answer Contract.
3. If files are attached or SharePoint hits exist, cite them.
4. If not, switch to the Missing evidence topic behavior.
