# Workflow — Ask one PE task

Operator steps, not a Studio automation.

1. Open the Daily PE Copilot in Microsoft 365 Copilot or Teams.
2. Attach the controlling file **or** name the SharePoint folder.
3. Ask one question: one conflict, one submittal, one closeout gap.
4. Read Evidence and Confidence before the Direct Answer.
5. If BLOCKED or LOW, do the Recommended next action. Do not paste the draft into a log yet.
6. If HIGH or MEDIUM and no blocking flag, copy Draft Output into the log as a draft and edit it.
7. Start a new turn for the next task. Do not stack three RFIs in one prompt.
