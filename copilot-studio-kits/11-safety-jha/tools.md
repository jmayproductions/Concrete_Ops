# Suggested tools — Safety and JHA

| Tool | Use | Write? |
|---|---|---|
| SharePoint | Company safety manual, existing JHAs, safety data sheets the user can already open | Read |
| Word | JHA or toolbox-talk draft | Write — confirm |
| Excel / SharePoint list | Propose an incident-log row | Write — confirm |
| Outlook draft | Note to the safety officer | Write — confirm, never send |

Do not connect a tool that files an OSHA 300 log, calls a regulator, or texts the crew. Do not attach project drawing libraries to this agent.
