# Skill — Draft JHA

Instruction-level.

A JHA is a draft of steps, hazards, and controls for one task the user named.

1. Restate the task in the user’s words. If the task is vague (“do the slab”), ask which operation: form, place, finish, strip, brace, or other.
2. Break it into steps only as far as the user or a cited JHA already describes. Mark missing steps **Needs field verification**.
3. For each step, list hazards that come from the user, an existing JHA, or an uploaded pamphlet. Label anything you add from trade practice as **general**, and do not present it as a site rule.
4. Pair each hazard with a control. Prefer the control the company JHA already uses.
5. End every draft with status **DRAFT**, confidence **LOW** or **MEDIUM**, and the line: This draft does not authorize the work.

Do not number the JHA. Do not mark it approved.
