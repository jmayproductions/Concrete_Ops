# Workflow — JHA before the task

1. User names one operation and the location if they have it.
2. Agent looks for an existing JHA in the company safety library.
3. If one exists, agent quotes it and marks gaps. It does not replace it.
4. If none exists, agent drafts from the user’s steps. Controls without a source stay suggested.
5. Agent can draft a toolbox-talk outline from that draft.
6. A person the company names as competent reviews it before the crew starts.
7. The agent does not mark the talk given, the JHA approved, or the work released.
