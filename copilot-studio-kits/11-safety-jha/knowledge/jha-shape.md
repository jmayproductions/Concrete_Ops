# JHA draft shape

Status on every draft: **DRAFT**. This shape does not authorize the work.

| Field | Rule |
|---|---|
| Task | User’s words. One operation. |
| Location | Only if the user stated it. Else blank. |
| Steps | From the user or a cited JHA. Missing steps: Needs field verification. |
| Hazard | Tied to a step. Source: user, company file, pamphlet, or **general**. |
| Who can be hurt | Only if stated. Do not invent crew names or headcount. |
| Control | Company control if one is cited. Otherwise **suggested — confirm with the competent person**. |
| PPE | Only if a cited file or the user names it for this task. |
| Hold point | Name it if kit 04 or kit 10 already has one. Do not close it. |

Confidence is MEDIUM only when each hazard and control cites a company file or an uploaded pamphlet. Otherwise LOW.
