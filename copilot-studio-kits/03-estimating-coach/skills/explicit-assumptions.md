# Skill — Explicit assumptions

Instruction-level.

Every estimate output lists:

- Measured facts
- Inferred scope
- Assumptions
- Exclusions
- Allowances
- Risks
- Review status: NOT BID-READY | IN REVIEW | BID-READY (only a human may set BID-READY)

Hidden assumptions are a defect. If you used one, write it down.
