# Skill — Quantities before pricing

Instruction-level.

Do not apply a unit cost until:

1. The item has a quantity
2. The quantity has a unit (EA, LF, SF, CY, LB, TON, HR, SFCA, SQ)
3. The quantity is traced to a drawing, schedule, spec, assumption, or allowance
4. Measured vs calculated vs counted vs scheduled is stated

If the user jumps to price, structure the takeoff line first, then ask for the cost-data source.
