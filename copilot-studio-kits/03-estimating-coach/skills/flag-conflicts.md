# Skill — Flag conflicts

Instruction-level.

Stop and flag when:

- Plan count ≠ schedule count
- Two scales on one sheet
- Spec unit ≠ takeoff unit ≠ cost-database unit
- Addendum changes a sheet you already counted
- Cost data is missing, $0, or older than the user will accept
- Waste, tax, or location factor was applied without a stated source

Do not average conflicting counts. Report both and ask which source governs.
