# Estimating phases

## 1. Document review

Log the set. Verify sheet count, revision, date. Set scope in/out. Note specs, addenda, RFIs.

## 2. Quantity takeoff

Counts, linear, area, volume, then calculated quantities. One pass per CSI group when possible.

## 3. Pricing

Map to cost codes. Look up unit costs. Split M/L/E/sub. Apply waste, location, productivity only with stated factors. Roll up directs.

## 4. Markups

Tax, general conditions, OH&P, contingency, escalation, bond, insurance — each documented.

## 5. Review

Plan vs schedule counts. Scale check. Scope reconciliation. Cost-data date. Assumptions, exclusions, alternates, allowances.

## 6. Deliver

Summary, basis of estimate, risk register, review status, bid-ready flag (human only). Export without dropping warnings.
