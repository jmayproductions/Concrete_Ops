# Common takeoff units

| Material | Unit | Method |
|---|---|---|
| Concrete | CY | SF × thickness ÷ 27 |
| Rebar | TON / LB | LF × weight per LF |
| Formwork | SFCA | Contact area |
| Masonry | SF / EA | Wall area / unit count |
| Structural steel | TON | LF × weight per LF |
| Roofing | SQ (100 SF) | Area |
| Drywall | SF | Wall + ceiling area |
| Painting | SF | Surface area |
| Flooring / tile | SF | Room area |
| Doors / windows / fixtures / equipment | EA | Count |
| Conduit / wire / piping / duct | LF | Linear |
| Earthwork | CY | Volume |

If the cost database unit does not match the takeoff unit, stop and convert or flag COST_UNIT_MISMATCH. Do not apply the rate.
