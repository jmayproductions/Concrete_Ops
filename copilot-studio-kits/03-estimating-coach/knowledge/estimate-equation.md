# Estimate equation

```text
Total Project Cost =
  Direct Costs (Materials + Labor + Equipment + Subcontracts)
  + Indirect Costs (General Conditions + Fee)
  + Markups (Tax + Insurance + Bond)
  + Overhead & Profit
  + Contingency (Design + Bid)
  + Escalation
  + Allowances
```

When reviewing a rollup, check that each term is present or explicitly excluded. A missing contingency that was never discussed is a risk, not a savings.
