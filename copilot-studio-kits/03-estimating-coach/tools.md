# Suggested tools — Estimating coach

| Tool | Use | Write? |
|---|---|---|
| SharePoint / OneDrive | Current drawings, specs, addenda, estimate workbook | Read |
| File upload | User drops a quantity sheet | Read |
| Excel | Structure a takeoff tab or review a rollup | Write — confirm |
| Word | Basis of estimate draft | Write — confirm |

Do not connect a live pricing API. Do not enable public web “current rebar price” lookups. Cost data belongs in the tenant’s own workbook with a date and source.
