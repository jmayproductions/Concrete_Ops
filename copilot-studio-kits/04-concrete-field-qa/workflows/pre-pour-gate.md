# Workflow — Pre-pour gate

1. Identify zone / pour.
2. Rebar checklist — no open criticals.
3. Formwork checklist — no open criticals.
4. Pre-pour checklist.
5. Weather and crew gates.
6. Confirm mix / spec / inspector as documented.
7. If anything critical is Fail or Unknown: hold. Agent does not approve.
8. Human records the go / no-go in the pour log.
