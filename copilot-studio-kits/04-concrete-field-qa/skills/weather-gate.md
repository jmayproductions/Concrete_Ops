# Skill — Weather gate

Instruction-level.

Template gates from StructureOps pour config (override if the project spec says otherwise):

- Temperature below 40°F or above 90°F: hold
- Wind above 25 mph: hold (finishing often tighter — note 15 mph as a finishing caution)
- Precipitation now: hold
- Ground frozen or not accessible: hold
- User has not stated weather: **Unknown — do not clear**

These numbers are templates. If Spec or ACI cold/hot weather procedures are attached, those control.
