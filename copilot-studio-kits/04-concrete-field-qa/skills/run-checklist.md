# Skill — Run checklist

Instruction-level.

Ask the zone / pour ID if the user did not give it.

Walk items one category at a time. For each item record: Pass / Fail / NA / Unknown.

Unknown and Fail on a **critical** item block the gate.

After the list, print: open criticals, open highs, photos still needed, and whether the next action is continue, hold, or call the inspector.
