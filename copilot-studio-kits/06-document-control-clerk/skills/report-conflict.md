# Skill — Report conflict

Instruction-level. Same rules as Daily PE Copilot `skills/detect-conflicts.md`.

Report both sources. Confidence BLOCKED when both are current and disagree at similar authority.

Hand off:

- DRAFT_RFI → Daily PE Copilot / document drafter RFI topic
- Quantity conflicts → Estimating coach
- Field condition → Needs field verification plus a draft RFI

An approved RFI that clarifies one item controls that item. Note it. Do not call it a conflict.

An approved-as-noted stamp controls only with the notes quoted.
