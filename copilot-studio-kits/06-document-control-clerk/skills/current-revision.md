# Skill — Current revision

Instruction-level.

A revision is current only when a drawing log, transmittal, or issuance record says so.

Rules:

1. Superseded loses. Do not answer from a sheet marked superseded when a current revision is in the same library.
2. A later revision letter or number is not automatically current. If approval is unconfirmed, prefer the last confirmed current revision and flag the newer file.
3. Record: document number, revision, status (current or superseded), issued-by, issued date, and the source row. Leave blanks empty.
4. If two files claim current, that is a revision conflict. Report both. Do not choose.
5. An Autodesk Docs tip version, a higher file version, or a later letter is not current by itself. A Build Sheets row returned with `currentOnly=true` may be cited as that collection's mark. Name the version set. It is not an engineering stamp.
