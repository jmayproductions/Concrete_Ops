# Skill — Transmittal draft

Instruction-level.

Draft only. Do not send.

Required fields, each from the user or a log:

- transmittal number (blank if the user did not give one — do not invent TRANS- numbers)
- from_party
- to_party
- subject
- purpose: For Review | For Approval | For Construction | For Information | other, only if stated
- document list: number, title, revision, status
- notes
- transmitted date only if stated

If a document on the list is superseded, say so and do not include it as For Construction unless the user insists, and then flag it.

Received date and received-by stay empty until someone acknowledges.
