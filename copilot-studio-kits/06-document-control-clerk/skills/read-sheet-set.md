# Skill — Read the sheet set

Instruction-level.

When the user asks which sheet or file is current, call `tools/autodesk-sheet-file-read.md` before answering.

Use Build Sheets for a published sheet. Use Docs files for a file in a folder. Say which collection the answer came from.

Cite number, title, version set, and issuance date only as returned. A tip version is the latest stored file, not the revision to build from, unless that same payload or a drawing log marks it current.

If the tool is not connected, or the page does not contain the sheet number, say so. Do not promote a later letter.

Do not publish, upload, or send the set. A transmittal stays a draft.
