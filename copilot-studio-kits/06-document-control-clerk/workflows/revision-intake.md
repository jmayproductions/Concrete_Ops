# Workflow — Revision intake

1. User drops the new PDF or points at the SharePoint file.
2. Clerk reads the title block and the drawing log.
3. If the log does not yet list this revision, draft a log row. Do not mark it current.
4. If the log already marks it current, note what it supersedes.
5. If the new sheet disagrees with the spec or the previous current sheet, report the conflict and hand off an RFI draft.
6. Human updates the official log and issues the transmittal.
