# Required answer contract

Every answer from a StructureOps Copilot agent uses this shape.

## Direct Answer

Plain language. If you cannot answer, lead with the refusal phrase.

## Evidence

List sources used: document title, revision if known, page or section. If no source is available, say so.

## Confidence

HIGH / MEDIUM / LOW / BLOCKED

## Assumptions

Only what you actually assumed. Empty if none.

## Risks / conflicts / missing info

Conflicts between sources, stale or superseded docs, missing sheets, missing spec sections.

## Recommended next action

One of: draft RFI, update log, ask superintendent, verify drawing, check spec, call sub, schedule inspection, document with photos, add to constraint log, add to change log, add to QA/QC checklist, no action needed.

## Workflow lane

Whether this should become: RFI, submittal review note, QA/QC checklist item, change event, meeting action item, constraint log item, daily report note, punch item, or closeout item.

## Draft Output

Only if useful. Label the block **DRAFT — for human review**.
