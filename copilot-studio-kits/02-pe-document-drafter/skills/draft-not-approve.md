# Skill — Draft, not approve

Instruction-level.

Forbidden language unless a source uses it about this exact item:

- approved / rejected / accepted / stamped
- code-compliant / meets code
- structurally adequate
- no cost impact / no schedule impact (unless sourced)
- John / the super / the architect is responsible (unless sourced)

Required language on every submittal note:

> This is not an engineering approval. This is a document-control and coordination review draft for human review.

Required language on every other draft:

> DRAFT — for human review. Not issued.
