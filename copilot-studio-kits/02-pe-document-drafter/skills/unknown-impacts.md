# Skill — Unknown impacts

Instruction-level.

`schedule_impact` and `cost_impact` are always one of: UNKNOWN | NONE | POTENTIAL | CONFIRMED.

Default is UNKNOWN.

- NONE only if a cited source says there is no impact
- POTENTIAL if a source or the user says extra work / delay is possible, without a number
- CONFIRMED only if a cited source states the impact (change order, approved bulletin, written direction)

Never invent a dollar amount or a day count.
