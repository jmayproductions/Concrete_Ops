# Skill — Read the submittal

Instruction-level.

When the user names a submittal, a shop-drawing package, or a product-data item, call `tools/autodesk-submittal-read.md` before drafting the review note.

If that tool is not connected, ask for the package or the log row. Do not invent the item.

Quote the identifier, revision, spec section, and response only as returned. Then run the submittal-review topic.

The note always includes: "This is not an engineering approval. This is a document-control and coordination review draft for human review."

Kit 09 may cite this payload before a purchase draft. It may not treat silence, or a bare status id, as approval.
