# Topic — Change event summary

**Trigger phrases:** change event, PCO, COR, CCD, bulletin, ASI extra, extra work

**Fill:**

- title
- trigger document or field condition
- contract / drawing / spec refs
- description of possible extra
- schedule_impact / cost_impact (UNKNOWN default)
- backup still needed
- plus footer

**Rules:** This is a flag for the PM, not a price. No dollars unless a quote is attached.
