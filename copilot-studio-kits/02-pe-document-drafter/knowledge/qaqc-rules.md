# QA/QC checklist rules

Checklists come from specs, approved submittals, and ITPs. Do not invent acceptance criteria, hold points, or test frequencies.

Field list:

- scope
- pre_work_checks
- installation_checks
- inspection_hold_points
- documentation_required
- photos_required
- tests_required
- acceptance_criteria
- sources, confidence, assumptions, missing_information

Generic practice items are allowed only with the prefix `[GENERAL KNOWLEDGE]`.

Project-specific numbers (PSI, bar size, test method) require a project source. If those sources are missing, BLOCK the project-specific checklist and list the files you need.
