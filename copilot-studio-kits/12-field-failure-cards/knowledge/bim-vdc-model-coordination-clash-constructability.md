## Out of this card

- Software training menus except where a setting or workflow directly creates a coordination, field-release, evidence, or safety failure

## When this shows up

- **Clash returns after it was resolved**
  Check first: current model versions; explicit test rerun; stable element IDs; changed-object impact; old versus new root condition.
- **One discipline is displaced**
  Check first: internal/shared origin strategy; named shared site; Project/True North; viewer transform; three common 3D points.
- **No clashes found**
  Check first: processed status; supported/clash-enabled format; model alignment; export completeness; intentional-intersection test.
- **Thousands of clashes**
  Check first: duplicate models/geometry; whole-file tests; set membership; root-condition grouping; tolerance/test type.
- **Model looks clear but field cannot install**
  Check first: installation/tool path; supports/bracing; tolerance stack; temporary sequence; verified existing conditions.
- **Issue says closed but geometry still clashes**
  Check first: workflow versus test timestamp; published/consumed version; promise versus implemented change; UI refresh; downstream release.
- **Elements visible in Revit are absent in federation**
  Check first: controlled export view; links/worksets/phases/options; file reader; element ID conversion; source/export object-count sentinels.
- **Shop, model, and points disagree**
  Check first: production authority; revision/hash lineage; source object GUID; coordinate frame; open issue/change cutoff.
- **Clash-free area still has RFIs**
  Check first: nonmodeled scope; LOD reliability; contract/model discrepancy; clearance/performance rules; constructability checklist.
- **Late design change after sign-off**
  Check first: changed-object set; closed-issue dependencies; fabricated/layout/installed exposure; formal authority; new release gate.

## Do this

- Identify the governed area/system, contract precedence, model responsibility/LOD, authorized uses, current file/object identities, coordinate authority, and required field/fabrication decision.
- Preserve versions and trace the failure through publish/share/consume, federation/export, scope/classification, sets/tests, triage/decision, implementation, downstream artifacts, and installed state.
- Reproduce with controlled models, three-point alignment, completeness sentinels, calibrated clash/clearance examples, constructability sequences, and current-model test reruns.
- Hold affected outputs/work until authorized correction, change-impact review, artifact/field disposition, clean readback, independent verification, and signed release are complete.

## Never do

- Choosing a convenient model, coordinate transform, tolerance, filter, suppression, or status after viewing an unwanted result
- Treating clash count, visual alignment, high LOD appearance, or an issue comment as proof of current authorized constructible geometry
- Closing issues or issuing fabrication/layout while the governing model/test has not been published, consumed, rerun, and downstream-reconciled
- Assuming unmodeled, unsupported, unprocessed, hidden, or omitted objects have no conflicts
- Making design-authority, code, liability, tolerance acceptance, or destructive field-correction decisions outside agent authority

## Handoff

Escalate to the VDC lead plus the designated designer, trade detailer/fabricator, superintendent/field engineer, survey/QC lead, owner, or contract authority whenever model precedence/LOD/scope is unclear, coordinates fail, content is missing, test validity is uncertain, constructability or performance is affected, decisions change design, or fabrication/layout/installed work is exposed.


Release rule: Release only when authoritative current models, common coordinates, complete purpose-fit scope, reliable LOD/LOI, current validated tests, constructability, authorized issue decisions, downstream artifact reconciliation, transparent residual risk, clean-environment readback, and signed field/fabrication gates all pass.

This card does not release the work.
