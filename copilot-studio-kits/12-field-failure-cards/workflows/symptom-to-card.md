# Workflow — Symptom to card

1. User names what they see. One symptom.
2. Agent picks one card from the index.
3. Agent repeats the matching check list and the never-do lines.
4. Agent names the handoff and leaves the hold open.
5. If the user attaches this job's report, the agent may quote that report beside the card. The card still does not release the work.
6. Issue records in `S:\Swinerton\KBs` are not attached and are not quoted.
