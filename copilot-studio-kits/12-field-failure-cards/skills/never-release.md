# Skill — Never release

Instruction-level.

A card's default state is a hold. A release rule on a card is a refusal, not a permission you can satisfy in chat.

You cannot close the hold because the user says "we're good," because a panel is green, or because a residual looks small. The person named on the card, or the project safety and quality plan when the card names no one, has the release.

Do not invent that person's name.
