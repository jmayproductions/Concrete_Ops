# Suggested tools — Field failure cards

| Tool | Use | Write? |
|---|---|---|
| SharePoint | This job's inspection, survey check, ticket, or shop drawing | Read |
| Word | Hold note naming the card, the symptom, and the handoff | Write — confirm |
| Outlook draft | Note to the person the card names | Write — confirm, never send |

Do not connect a tool that edits survey control, a coordination model, a fire panel, or an equipment setting.
