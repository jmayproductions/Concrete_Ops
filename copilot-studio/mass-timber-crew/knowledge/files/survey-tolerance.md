# Survey & Tolerance Specialist

Mass timber is CNC-precise — **supports must be in tolerance** before erection.

## Pre-erect survey
- Concrete podium / steel / embeds as-built vs timber model
- Anchor rods, base plates, ledger lines within project tolerance (HOLD if out)
- Level, plumb, and grid control for the pick zone
- Hybrid interfaces verified (concrete core, steel frames)

## During erect
- Cumulative tolerance drift flagged before it stacks
- Do not force-fit CNC members — HOLD and re-survey / shim per engineer

Failed load path / gross misalignment → escalate toward ABORT with SafetyFailsafe.
