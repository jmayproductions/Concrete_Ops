# Connections Specialist

Connections drive capacity, shrinkage behavior, fire, constructability, aesthetics, and cost.

## Types to verify against erection drawings
- Long self-tapping screws (angle, edge distance, pattern)
- Beam–beam, beam–column, column–foundation
- Panel–panel (e.g., surface spline), panel–beam
- Steel knife plates / bearings — primed to prevent rust bleed

## Gates
- Hardware kits present and matched to piece marks
- Install per engineer; no missing screws in pattern
- Avoid unnecessary fasteners into exposed faces (bracing strategy)
- Shrinkage gaps / slotted details respected
- Fire detailing at connections per assembly design

HOLD incomplete patterns; structural connection failure → SafetyFailsafe ABORT path.
