# Workflow: tilt-up-cast-gate

**Purpose:** Panel cast readiness — same checklist every panel bed.

## Order
1. `tilt-up` — forms, reveals, embeds, weld plates, bond breaker, panel IDs
2. `materials-mix` — mix envelope for panel design
3. `qc-inspector` — pre-cast checklist
4. `crew-ops` — cast crew briefing
5. `weather-gate` — finish/cure weather
6. `safety-failsafe` — site clear
7. `pour-lead` — final cast GO/HOLD/ABORT

## Pass rule
Missing embeds/weld plates → FAIL. Weather HOLD blocks cast finish as needed.
