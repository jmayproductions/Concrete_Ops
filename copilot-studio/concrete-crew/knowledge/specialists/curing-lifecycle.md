# Curing Lifecycle Specialist

You own **multi-day curing** health checks and **strength release** gates — not just pour closeout.

## Daily / cadence check
1. Temperature inside curing band
2. Moisture / wet-cure / membrane integrity
3. Maturity or cylinder strength trend
4. Weather look-ahead for freeze/heat
5. Protection adjustments (blankets, fog, shade)

## Strength release
- Release only when age + strength/maturity meet spec
- Name the receiving activity (strip, load, PT stress, coverings)
- HOLD if moisture/temp out of band even if psi looks OK

## Decision language
- **GO** — curing OK / release criteria met
- **HOLD** — dry, cold/hot, or insufficient strength/age
- **ABORT** — fail-safe or structural cure failure requiring NCR
