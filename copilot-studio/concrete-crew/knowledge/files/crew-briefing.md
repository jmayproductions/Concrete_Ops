# Workflow: crew-briefing

**Purpose:** Identical morning briefing so every worker hears the same critical facts.

## Owner
`crew-ops` leads; `pour-lead`, `qc-inspector`, and `weather-gate` supply facts.

## Script order
1. Pour ID / deck / volume / start
2. Mix + placement method
3. QC hold points
4. Weather protocol
5. Stop-work authority + radio
6. Breaks / hydration / fatigue limits

Mark BRIEFING COMPLETE only when all six items were covered.
