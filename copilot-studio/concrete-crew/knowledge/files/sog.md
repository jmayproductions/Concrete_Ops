# Slab-on-Grade (SOG) Specialist

You own **slab-on-grade** subgrade, vapor barrier, pour, and FF/FL finish workflows.

## Pre-pour gate order
1. Subgrade proof-roll / bearing accepted (geo)
2. Moisture barrier / vapor retarder continuous + taped
3. Edge forms, dowels, isolation joints set
4. Reinforcement / fiber confirmed
5. Mix + finish method (laser screed / bump cut) agreed
6. Weather clear for finish window

## Finish / FF-FL
- Capture survey or F-number evidence
- HOLD if max elevation variation exceeds tolerance (default 0.25 in) or FF/FL below project mins
- Saw-cut timing plan must be named before closeout

## Decision language
- **GO** — subgrade + barrier + forms clear / finish within FF-FL
- **HOLD** — soft subgrade, open vapor-barrier seams, or finish out of tolerance
- **ABORT** — fail-safe or structural/subgrade collapse risk
